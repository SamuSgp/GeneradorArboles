# Generador de Árboles de Derivación y AST.

## Integrantes

*Samuel González Pérez 
*Samuel Lopez Binilla

## Descripción

Aplicación desarrollada en Java utilizando Programación Orientada a Objetos que permite:

* Definir gramáticas libres de contexto (CFG)
* Generar derivaciones izquierdas y derechas
* Construir árboles de derivación
* Generar árboles sintácticos abstractos (AST)

## Tecnologías utilizadas

* Java
* Swing
* Visual Studio Code
