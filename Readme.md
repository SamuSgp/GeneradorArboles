# Derivation Tree and Abstract Syntax Tree Generator for Context-Free Grammars

## ST0244 - Programming Languages and Computing Paradigms
### School of Applied Sciences and Engineering - EAFIT University

---

## Description

This project is a graphical interface application developed as part of Practice II for the course ST0244. The program allows the user to define a context-free grammar (CFG) and a target expression, and from that input it generates the following outputs:

- Step-by-step derivation of the expression using left or right expansion, as selected by the user.
- Derivation tree that visually represents each expansion step of the grammar until the final expression is reached.
- Abstract Syntax Tree (AST) that simplifies the derivation tree by omitting redundant nodes and highlighting the key structural elements of the expression.

---

## Features

- Grammar definition using BNF or similar standard format.
- Left derivation and right derivation modes selectable by the user.
- Graphical visualization of the derivation tree.
- Graphical visualization of the Abstract Syntax Tree.
- Graphical user interface (GUI).

## How to Run

1. Clone this repository.
2. Install the required dependencies.
3. Run the main file of the application.
4. Enter the grammar rules in the corresponding field.
5. Enter the target expression.
6. Select the derivation type (left or right).
7. Click the button to generate the derivation and visualize the trees.
